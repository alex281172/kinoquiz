# Киноквиз: советская классика

Тренажёр по советскому кино. Удобнее всего проходить на телефоне или планшете.

Квизы (переключаются на главной):
- **Классика**: 50 вопросов о фильмах Гайдая и Рязанова.
- **Чья фраза?**: 20 фильмов, в каждом вопросе нужно найти одну фразу из четырёх, которую выдумала редакция «КП» ([оригинальный тест](https://www.kp.ru/daily/26489/3358363/)).
- **Сложный**: 45 вопросов о композиторах кино, исполнителях, ВИА, режиссёрах и наградах, с пояснением после каждого ответа.

Режимы:
- **Тренировка**: вопросы идут вперемешку, на ошибку вопрос возвращается позже.
- **Работа над ошибками**: только вопросы, на которых последний ответ был неверным.
- **Карточки**: видите вопрос, нажимаете, видите ответ.
- **Квиз на результат**: все вопросы по порядку, в конце итоговая оценка.

Прогресс сохраняется в браузере. После первого открытия сайт работает без интернета. Его можно добавить на главный экран: «Поделиться» → «На экран Домой».

Вопросы лежат в `questions.js`, у каждого квиза отдельный блок. Поле `a` — номер правильного варианта (0 = А, 1 = Б, 2 = В, 3 = Г), `e` — пояснение после ответа. После правки вопросов увеличьте версию в `sw.js`.
